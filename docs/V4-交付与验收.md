## 数据契约

每个课程包包含 `domainId / question / prerequisites / hours / outcomes / connections / sources / stages`。

阶段包含 `key / title / lesson[] / concepts[] / workedExample / exercise / quiz[] / project / prompts[]`。每阶段至少两段实质课文（合计至少240字符）、两个概念、两步推理、带具体答案的练习、一题四选项解析题、项目交付及评价标准。240字符是结构性下限，不是内容质量证明。

`npm run build` 将新数据同步到原来的300个 `content/{id}/{stage}.json`，并建立全文搜索索引，避免旧接口仍返回模板。检索内容包括讲解、概念、推演和练习。

## 评价边界

- 「已研习」只记录活动完成，不表示学科掌握。测验、项目自评分开存储。
- 单题自测只用于提取练习，不是标准化能力测量。项目需要教材学习、真实作品和外部反馈。
- 全量自动测试验证数据与确定性功能，不证明跨100领域知识无误；课程未经专家逐篇同行评审。
- 外部链接含英文，访问取决于出版机构和网络环境。推荐来源是继续深入的入口，不声称每段课文都已被该机构审定。
- 手机测试使用浏览器视口模拟，不能代替全部实体设备和微信内置浏览器测试。
- GitHub静态托管不提供账户、在线AI、云同步或服务端管理。旧演示管理口改为内容标准页。
