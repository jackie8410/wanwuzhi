# 世间万物 · V4

成年人从零开始理解世界的知识窗口。沿用 GitHub Pages 与 `learnforeverything.cn` 域名，保留原微信小店二维码。

## 使用

```sh
npm run build
npm test
npm run preview
```

打开 `http://127.0.0.1:4173`。无需依赖安装、API 密钥或服务器数据库。

- `data/curricula/1.json` 至 `100.json`：100 个领域的三阶段课程源文件。包含实质讲解、概念、推演、练习答案、测验解析、项目、导师提示和来源。
- `scripts/build-curriculum.mjs`：生成领域摘要、全文索引与兼容原路径的 300 份课程 JSON。稳定重排测验选项，保留正确答案。
- `assets/app.js`、`assets/style.css`：响应式界面、阅读与本地记录。
- `assets/labs.js`：5 类教学模型，分布于 10 个领域的入门课。
- `scripts/validate-curriculum.mjs`：全量数据契约、唯一性、链接格式、旧内容同步、域名及二维码检查。
- `scripts/labs.test.mjs`：验证概率、均衡、复利、能量、二分查找计算。

## 内容标准

三阶段为「入门—进阶—综合研习」。本站研习课与开放教材、大学公开课共同组成进一步学习的路线。达到优秀本科毕业生能力需要完成教材习题、持续练习和经反馈修订的项目，本站阅读和自评不等同于学位或专业认证。

V4 内容由 AI 辅助原创编写，已有结构性自动校验与代表性人工抽检，尚未经各领域专家逐篇同行评审。引用入口指向开放教材、大学和原始机构；应根据具体章节阅读并核实，不能把入口列表当作逐句引用证据。教学数值与情境须按标注解释。

旧版占位书名与虚构 ISBN 已从当前书籍数据中退役，课程推荐由真实学习资源替代；商店库存以微信橱窗为准。历史 `wanwuzhi-v3.4-deploy/` 仅为旧版本存档，不是当前部署入口；`scripts/upgrade-learning-content.mjs` 为旧生成器，不应用于 V4。

## 更新与发布

1. 修改课程 JSON 或界面；运行 `npm run build` 和 `npm test`。如修改1–30的自测题，请同步维护 `scripts/refine-quiz-explanations.mjs` 中的题目和正确答案核对，构建会自动应用逐题解析。发布时同步更新前端版本查询参数。
2. 本地预览，检查桌面、手机、测验、笔记、导入导出和二维码。
3. 审查变更后推送到当前 Pages 使用的 `main` 分支；GitHub 自动构建发布。
4. 确认对应提交的 Pages 工作流成功，再核对线上版本与代表性课程。

维护时保留 `CNAME` 和 `qr/store-qr.png`。不需要更改 Pages 设置。学习记录完全在当前浏览器，跨设备使用学习台的 JSON 导出/导入。导入只增加本机不存在的记录。

详见 [V4交付与验收](docs/V4-交付与验收.md)。`docs/` 中的 2026-05 文档记录旧版规划，V4 的实现、命令与限制以此 README 和 V4 文档为准。
